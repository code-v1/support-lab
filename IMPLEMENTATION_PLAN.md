# Support Lab implementation

1. **Working foundation:** persistent DemoDesk accounts, real login/export failures, bounded support tools, deterministic verification, seeded personas.
2. **Agent loop:** configurable OpenAI/Gemini routing, persistent turn-by-turn orchestration, audited tools, escalation, verified learning and validated JSON workflows, reset/replay.
3. **Observable interface:** six dashboard views, browser voice playback and pause controls, working DemoDesk, optional Playwright reproduction.
4. **Verification:** unit/integration checks for state, permissions, workflow safety, knowledge gating, replay and orchestration; browser tests; production build.

Progress previews follow each milestone. AI calls require configured provider keys; no fabricated calls or results are seeded.
